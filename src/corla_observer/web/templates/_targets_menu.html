How this works {% if m.page_intro %}

{{ m.page_intro }}

{% endif %}

Which of {{ county }}'s own (local) contests random draws from their cards would help most. Local contests carried by exactly the same cards form one sampling domain: a draw from it counts for every one of them. Each contest's pooled risk is Kaplan-Markov over CORLA's draws that landed on its cards, counted with multiplicity, plus the domain draws made here, with the discrepancies seen on them; risk limit {{ m.limit }}. Extra draws are assumed to show no discrepancy until examined. Draws are with replacement: a card drawn twice is pulled once and counted twice. A draw joins the working list below.

○ {{ m.style_note }}

The suggestion spreads the budget ({% if menu.inputs.budget is not none %}by default {{ menu.inputs.budget_source }}, {{ menu.inputs.budget }}{% else %}by default {{ m.default_budget }}: no allowed total is recorded for {{ county }}{% endif %}). First, each domain holding an unseen local contest or a tie that no domain draw has reached gets one draw (an uncontested one too: one card checks that the CVR records it); the rest goes by minimax (lower the highest risk first) or ladder (cheapest domains under 90%, 50%, 20%, 10%, then {{ m.limit }}). {{ m.tie_note }}{% if chosen %} ({{ 'Ladder' if m.strategy == 'minimax' else 'Minimax' }} would bring the highest risk to {{ m.pct(m.allocations['ladder' if m.strategy == 'minimax' else 'minimax'].after) }}.){% endif %}

Each contest is thin (pooled risk above {{ m.limit }}) or settled, and has any of these tags: {{ badge('info', 'unseen') }} no card of the official sample carried it (domain draws are shown apart: “seen by N domain draws”); {{ badge('high', 'flagged') }} a discrepancy was found on its cards, with its types; {{ badge('tag', 'uncontested') }} no more candidates than seats, so no risk; {{ badge('tag', 'recount') }} a margin of at most 0.5% of the highest vote, or for a multi-winner contest of the lowest winner's votes (C.R.S. 1-10.5-101), for information only: Colorado's recounts usually re-tabulate by machine, so it is checked like any other; {{ badge('tag', 'tie') }} a margin of zero: each card checks the CVR's count, but the risk can't fall. A domain is on the menu when any of its local contests is unseen, thin or flagged.
