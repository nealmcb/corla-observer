Inputs supplied by hand

Audit center data ranks first (CORLA's contest list, then the manifests, then the target list's margin, denominator and cards per ballot), then the election night results; an input supplied by hand is used only where none of those has the value yet, and a later posting replaces it by itself (the contest's notes above say so). To supply one, add an [[estimate]] (a contest's margin, or winner's and loser's votes, its name in the results, or its ballot cards) or a [[county_estimate]] (a county's ballots cast, cards per ballot or ballot cards) to the workspace's overrides.toml, each with its reason, and apply it with corla-observer map apply: it is recorded in the event log like every override.
